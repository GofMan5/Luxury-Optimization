# Support

Use GitHub Issues for reproducible bugs and feature proposals. Include:

- `Luxury-Optimization ... version` output;
- operating system and architecture;
- the exact command and sanitized output;
- whether the problem reproduces with the recommended profile;
- before/after measurements for performance claims.

Use GitHub Discussions for setup questions if Discussions are enabled. Security reports belong in private Security Advisories, not Issues.

This is a community project. There is no guaranteed response time or warranty.
